Smart AI Chatbot

KARTHI KINGDOM is a next-generation conversational AI system that allows users to chat naturally using a clean and modern interface. It uses the Gemini AI model to generate intelligent responses and supports features like real-time message saving, chat access, login, and message sharing.

What Makes It Special?

This chatbot is designed not just for interaction, but for user convenience and experience.
Every conversation is automatically stored and can be viewed, renamed, deleted, or shared later.
The typing animations and formatted message display give a premium modern chat feel.

It provides an AI assistant experience that feels seamless and human-friendly.

 How It Works

When a user sends a message, it is processed through the Gemini API, and the result will be shown instantly.
If the user is logged in using Google, the messages get saved in Firestore and become part of chat history.
Each chat session is created automatically and organized neatly on the left sidebar.

All messages are rendered with markdown formatting, so code, steps, and structured content look clean.

🔐 Secure & Personalized

Users can login using their Google account and access their own chats securely.
For new users, anonymous mode is also supported so they can use the chatbot immediately without login.

Chats are stored per account, so each user has isolated history and access to their own conversations.
